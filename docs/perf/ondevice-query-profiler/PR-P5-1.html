Verdict

The vector-only path passes the P5 quality gate: recall_vectoronly@10 = 1.00, above the 0.90 threshold in DESIGN-P5. On this 500-chunk collection there is no evidence that the current i8-dequant HNSW graph settings require an immediate M or ef_search increase.

The shipped hybrid path intentionally measures a different behavior: BM25/RRF reordering against a pure-vector f32 ground truth. Its low mean, recall_hybrid@10 = 0.08, says BM25 dominates or heavily reorders this synthetic query set. It should not be read as an HNSW quality failure.

Key interpretation: vector-only recall isolates graph approximation plus i8 quantization error against the f32 corpus. Hybrid recall is an end-to-end reorder signal and needs a relevance-labeled or hybrid-aware ground truth before using it as a product-quality verdict.

Trade-offs

The run uses a deterministic synthetic fixture with 500 chunks in the measured collection. It is good enough to validate the current vector index quality path, but it is not a broad product relevance benchmark.

The hybrid number is intentionally harsh because the ground truth is pure f32 cosine. A future product-facing hybrid-quality report should compare against labeled relevance, a hybrid-aware oracle, or separate semantic and lexical expected sets.
