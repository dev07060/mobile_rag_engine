# MiniLM Model Pack (not in git)

Install the default Model Pack here from the `example/` directory:

```bash
dart run mobile_rag_engine:setup --preset stable-minilm-l6-v2-arm64-en --output assets/models/minilm --skip-host-config
```

Then run the app with `--dart-define=EXAMPLE_MODEL=minilm` (the default).
