# 암호 바꾸기

특히 누군가가 암호를 알아챘다면 때때로 암호를 바꾸는게 바람직합니다.

여러분의 계정이 아닌 사용자 계정을 편집하려면 관리자 권한이 필요합니다.

- 사용자를 눌러 창을 엽니다.

- 암호 옆 ····· 레이블을 누릅니다. 다른 사용자의 암호를 바꾸려면 우선 창을 잠금 해제하고, 기타 사용자에서 암호를 바꾸려는 계정을 선택합니다.

- 현재 암호를 입력하고 새 암호를 입력합니다. 새 암호 확인 입력창에 새 암호를 다시 입력합니다.

- 아이콘을 눌러 임의 암호를 자동으로 만들 수 있습니다.

- 바꾸기를 누릅니다.

우수한 암호를 지정했는지 확인합니다. 계정을 좀 더 안전하게 지킬 수 있게 해줍니다.

로그인 암호를 새로 고치면, 로그인 키 모음 암호를 사용자 계정 암호와 동일하게 업데이트합니다.

사용자 암호를 잊었다면 관리자 권한을 지닌 사용자가 암호를 바꿔줄 수 있습니다.
