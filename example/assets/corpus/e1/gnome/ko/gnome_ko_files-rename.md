# 파일 또는 폴더 이름 바꾸기

다른 파일 관리자에서와 같이, 파일 에서도 파일 이름 또는 폴더 이름을 바꿀 수 있습니다.

## 파일 또는 폴더 이름을 바꾸려면:

- 항목에 포인터를 올려두고 오른쪽 단추를 누른 후 이름 바꾸기를 선택하거나, 파일을 선택한 후 F2키를 누릅니다.

- 새 이름을 입력하고 Enter키를 누르거나 이름 바꾸기를 누릅니다.

파일 이름을 바꿀 때, 파일 확장자 부분(마지막 . 다음 부분)이 아닌 파일 앞 부분만 선택한 상태입니다. 확장자는 보통 파일 형식이 무엇인지 (예: file.pdf 파일은 PDF 문서임) 나타내며 보통 여러분께서 바꾸고 싶어하지 않는 부분입니다. 확장자도 마찬가지로 바꾸려면 파일 이름 전부를 선택하고 바꿉니다.

## 올바른 파일 이름 문자

파일 이름에는 /(슬래시) 문자를 제외하고 어떤 문자든 사용할 수 있습니다. 그러나 어떤 장치에서는 파일 이름에 더 많은 제한을 가하는 파일 시스템을 사용하기도 합니다. 따라서 파일 이름에 |, \, ?, *, <, ", :, >, / 문자는 가장 피하는게 좋은 습관이 되겠습니다.

파일 이름에 .이 처음 문자로 온다면 파일 관리자에서 해당 파일을 보려고 하면 숨김 상태가 됩니다.

## 일반 문제

파일 이름을 이미 사용하고 있습니다

동일한 이름을 지닌 파일 또는 폴더를 같은 위치에 돌 수 없습니다. 만약 폴더에 있는 작업중인 파일과 동일한 이름으로 파일 이름을 바꾼다하면, 파일 관리자에서 허용하지 않습니다.

파일 또는 폴더 이름은 대소문자를 구분합니다. 따라서 File.txt는 FILE.txt와는 다릅니다. 이런식의 다른 파일 이름은 추천하지는 않지만 허용합니다.

파일 이름이 너무 깁니다

어떤 파일 시스템에서는 파일 이름의 길이가 255 글자를 넘을 수 없습니다. 255 글자 제한은 파일 이름과 파일 경로 모두(이를테면, /home/cheolsoo/Documents/work/business-proposals/… )에 해당하기에 가능하다면 긴 파일 이름 및 긴 폴더 이름을 피해야 합니다.

파일 이름 바꾸기 옵션을 사용할 수 없게 바뀌었습니다

이름 바꾸기 항목이 흐릿하다면 파일 이름을 바꿀 권한이 없다는 의미가 되겠습니다. 이 파일의 이름을 바꿀 때 위험성을 동반하며, 보호 파일의 이름을 바꿨을 때 시스템이 불안정해질 수 있습니다. 자세한 내용은 파일 권한 설정을 봅니다.
