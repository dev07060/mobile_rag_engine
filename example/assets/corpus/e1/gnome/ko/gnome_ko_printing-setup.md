# 로컬 프린터 설정

시스템에서는 연결한 여러가지 모든 프린터를 한번에 인식할 수 있습니다. 대부분의 프린터는 USB 케이블로 컴퓨터에 직접 연결하지만 일부 프린터는 유무선 네트워크에 연결하기도 합니다.

프린터를 네트워크에 연결했다면 자동으로 설정하지 않습니다. 설정의 프린터 창에서 추가해야 합니다.

- 프린터를 켰는지 확인합니다.

- 적당한 케이블로 시스템에 프린터를 연결합니다. 시스템에서 드라이버를 검색하는 등 화면의 동작을 볼 수 있으며 해당 드라이버를 설치할 때 사용자 인증을 요구할 수 있습니다.

- 시스템에서 프린터 설치가 끝나면 메시지가 나타납니다. 테스트 페이지 인쇄를 선택하여 시험 페이지를 인쇄하거나, 프린터 설정에서 추가 옵션 설정을 바꿉니다.

프린터를 자동으로 설정하지 않았다면 프린터 설정을 추가할 수 있습니다:

- 현재 활동 개요를 열고 프린터 입력을 시작합니다.

- 프린터를 누릅니다.

- 시스템에 따라 우측 상단 구석의 잠금 해제 단추를 누른 후 암호를 물어보면 암호를 입력해야합니다.

- 화면에 뜬 창에서 새 프린터를 선택하고 추가를 누릅니다.

- 프린터를 자동으로 발견하지 못했지만 네트워크 주소를 알고 있다면 대화상자 하단의 텍스트 입력 상자에 주소를 입력하고 추가를 누릅니다

프린터가 프린터 추가 창에 나타나지 않는다면 프린터 드라이버를 설치해야 할 수도 있습니다.

프린터를 설치한 다음에는 기본 프린터를 바꿀 수 있습니다.
