# 하드 디스크 문제 확인

## 하드 디스크 검사하기

하드 디스크는 자체 상태 검사 도구 SMART(자체 감시, 분석, 보고 기술)가 있어 디스크 잠재 문제를 계속 점검할 수 있습니다. SMART는 또한 디스크가 고장 직전일 경우 중요한 데이터를 잃지 않도록 경고해주기도 합니다.

SMART를 자동으로 실행하진 하지만 디스크 프로그램을 실행하여 디스크 상태를 검사할 수 도 있습니다:

## 디스크 프로그램으로 디스크 상태 검사하기

- 현재 활동 개요에서 디스크를 엽니다.

- 좌측의 저장장치 목록에서 검사하고자 하는 디스크를 선택합니다. 디스크 정보와 상태가 나타납니다.

- 메뉴 단추를 누른 후 SMART 데이터 및 자체 검사…를 선택합니다. 전체 평가에서 “디스크 이상 없음”이 떠야 합니다.

- SMART 속성에서 추가 정보를 보거나 자체 검사 시작 단추를 눌러 자체 검사를 실행합니다.

## 디스크가 정상상태가 아니라면 어떻게 할까요?

전체 평가에서 디스크가 정상 상태가 아니라고 나타난다 하더라도, 알림이 뜨지는 않습니다. 그러나 데이터 손실을 피하려면 백업을 준비하는게 좋습니다.

“고장 직전” 상태가 뜨면, 디스크는 여전히 상당한 정상 상태지만, 곧 고장 상태에 돌입할 징후를 발견한 상태입니다. 하드 디스크(또는 컴퓨터)가 오래되지 않았다면, 최소한의 상태 검사에서 가끔씩 이 메시지를 볼 수 있습니다. 중요한 파일을 정기적으로 백업 하고 장치가 잘못됐는지 주기적으로 디스크 상태를 검사해야합니다.

만약 문제가 생겼다면 컴퓨터 또는 하드디스크를 전문가에게 맏겨 추가 진단 또는 수리를 진행하는 것이 좋습니다.
