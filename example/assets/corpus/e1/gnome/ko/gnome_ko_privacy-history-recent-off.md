# 파일 사용 내역 추적 끄거나 제한하기

최근 사용한 파일 및 폴더를 추적하면, 파일 관리자에서 다루던 파일과 프로그램의 파일 대화 상자에서 쉽게 찾을 수 있게 합니다. 파일 사용 기록 개인 정보를 그대로 두거나 최근 기록만 추적하게 하고 싶을 때가 있습니다.

## 파일 사용 내역 추적 끄기

- 파일 사용 내역 및 휴지통을 눌러 창을 엽니다.

- 파일 사용 내역 스위치를 끕니다.

- 이 기능을 다시 켜려면 파일 사용 내역 스위치를 켭니다.

- 기록 지우기… 단추를 눌러 기록을 즉시 제거합니다.

이 설정은 웹 브라우저에서 여러분이 방문한 웹 사이트 저장 정보에 영향을 주지 않습니다.

## 파일 사용 내역 추적 허용 시간 제한하기

- 현재 활동 개요를 열고 파일 사용 내역 및 휴지통 입력을 시작합니다.

- 파일 사용 내역 및 휴지통을 눌러 창을 엽니다.

- 파일 사용 내역 스위치를 켰는지 확인합니다.

- 파일 사용 내역 기간에서 파일 사용 내역을 유지할 기간을 선택합니다. 1일, 7일, 30일, 계속 중 하나를 선택합니다.

- 기록 지우기… 단추를 눌러 기록을 즉시 제거합니다.
