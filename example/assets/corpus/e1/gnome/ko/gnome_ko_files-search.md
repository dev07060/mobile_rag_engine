# 파일 검색

파일 관리자에서 이름 또는 형식을 기반으로 파일을 검색할 수 있습니다.

## 검색

- 현재 활동 개요에서 파일 프로그램을 엽니다.

- 원하는 파일이 특정 폴더 아래에 있다는걸 안다면, 해당 폴더로 이동합니다.

- 파일 이름에 있는 단어 또는 복수의 단어를 입력하면 검색 표시줄에 나타납니다. 예를 들면, 청구서마다 “Invoice” 단어를 넣었다면 Invoice를 입력합니다. 단어는 대소문자를 가리지 않습니다.

- 검색 표시줄에 단어를 직접 입력하는 대신, 도구 모음에서 아이콘을 누르거나 Ctrl+F키를 누를 수 있습니다.

- 날짜별, 파일 형식별, 파일 전문, 파일 이름을 대상으로 검색 범위를 좁힐 수 있습니다.

- 검색 구분을 적용하려면 파일 관리자 아이콘의 좌측에 있는 드롭 다운 메뉴 단추를 선택한 후 검색 구분을 선택합니다:

- 언제: 검색 희망 시점으로 얼마나 되돌려야 할까요?

- 무엇을: 항목 형식은 뭘까요?

- 검색 구분을 제거하려면 제거하려는 구분 태그 앞의 X를 선택합니다.

- 검색 결과에 나타난 파일은 파일 관리자의 임의의 폴더에서 행하는 바와 같이 열기, 복사, 삭제 등의 방식으로 처리할 수 있습니다.

- 도구 모음에서 을(를) 한 번 더 눌러 검색에서 빠져나간 후 폴더로 되돌아옵니다.

## 파일 검색 개별 지정

파일 프로그램에서 각 디렉터리를 검색 조건에 넣거나 뺄 수 있습니다. 어떤 디렉터릴르 검색할 지 개별 설정하려면:

- 현재 활동 개요를 열고 검색 입력을 시작합니다.

- 결과에서 설정 ▸ 검색을 선택합니다. 검색 설정 창을 엽니다.

- 위치: 일반 홈 디렉터리 위치 목록을 보여줍니다

- 책갈피: 파일 프로그램에 책갈피로 등록해둔 디렉터리 위치를 보여줍니다

- 기타: + 단추로 추가한 디렉터리 위치를 보여줍니다.
