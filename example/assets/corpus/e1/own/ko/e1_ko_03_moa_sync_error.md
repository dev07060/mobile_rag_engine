# 은행 연동 오류 해결 방법

## 오류 코드 E102
은행이 비밀번호 변경을 요구한 경우입니다. 은행 앱이나 홈페이지에서 비밀번호를 바꾼 뒤, 모아가계부의 연결 관리에서 해당 은행을 눌러 새 비밀번호를 다시 입력하세요.

## 오류 코드 E205
인증서 유효기간이 지났습니다. 인증서를 갱신한 뒤 연결을 끊고 다시 연결해야 합니다.

## 내역이 일부만 들어올 때
은행 점검 시간(대부분 밤 11시 30분부터 새벽 0시 30분까지)에는 일부 내역이 빠질 수 있습니다. 점검이 끝난 뒤 다음 자동 동기화 때 채워집니다.

그래도 해결되지 않으면 앱의 고객센터 메뉴에서 오류 화면을 첨부해 문의해 주세요.
