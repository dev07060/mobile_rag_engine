CSS 프레임워크(CSS framework)는 CSS(Cascading Style Sheets) 언어를 사용하여 더 쉽고 표준을 준수하는 웹 디자인을 가능하게 하는 라이브러리이다. 이러한 프레임워크의 대부분은 적어도 하나의 그리드를 포함하고 있다. 더 기능적인 프레임워크는 더 많은 특징과 추가적인 자바스크립트 기반 기능을 제공하지만, 대개 디자인 지향적이며 대화형 UI 패턴에 초점을 맞춘다. 이러한 세부 사항은 CSS 프레임워크를 다른 자바스크립트 프레임워크와 구별 짓는다.
주목할 만하고 널리 사용되는 두 가지 예로는 부트스트랩과 파운데이션이 있다.
CSS 프레임워크는 다양한 모듈과 도구를 제공한다:

초기화 스타일 시트 (reset style sheet)
특히 반응형 웹 디자인을 위한 그리드
웹 타이포그래피
스프라이트나 아이콘 폰트 형태의 아이콘 세트
말풍선, 버튼, 폼 요소의 스타일링
아코디언, 탭, 슬라이드쇼 또는 모달 윈도(라이트박스)와 같은 그래픽 사용자 인터페이스의 일부
동일한 높이의 콘텐츠를 만들기 위한 이퀄라이저
자주 사용되는 CSS 헬퍼 클래스 (left, hide 등)
더 큰 프레임워크들은 Less나 Sass와 같은 CSS 해석기를 사용한다.
