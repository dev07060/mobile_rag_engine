# 상태 표시줄

상태 표시줄(status bar)은 일반적으로 창의 하단에 위치하며 정보 영역을 제공하는 그래픽 제어 요소이다. 정보를 그룹화하기 위해 여러 섹션으로 나뉠 수 있다. 주로 해당 창의 현재 상태에 대한 정보를 표시하는 역할을 하지만, 일부 상태 표시줄에는 추가 기능이 있다. 예를 들어, 많은 웹 브라우저에는 보안 또는 개인 정보 보호 정보를 팝업으로 표시하는 클릭 가능한 섹션이 있다.
상태 표시줄은 주로 콘솔 기반 애플리케이션에서 텍스트 기반으로 나타날 수도 있으며, 이 경우 대개 80x25 텍스트 모드 구성의 마지막 행에 위치하여 상단 24개 행을 애플리케이션 데이터용으로 남겨둔다. 보통 이 상태 표시줄(이러한 맥락에서는 상태행(status line)이라 불림)은 애플리케이션의 현재 상태와 유용한 단축키를 표시한다. 한 가지 예로 1970년대 유닉스(UNIX) 또는 최신 리눅스 시스템의 'vi' 텍스트 편집기가 있다.
상태행은 관련 정보의 시야를 가릴 수 있는 화면 중앙의 팝업 메시지 대신, 미리 정의된 영역에 조언 메시지를 표시하기 위해 30년 이상 사용되어 왔다.
때때로 비디오 게임은 플레이어의 중요한 정보나 HUD(히트 포인트, 생명력, 점수 등)를 화면 상단이나 하단의 유사한 띠 모양 영역에 배치하는데, 이것 역시 상태 표시줄이라고 부른다.

용도
상태 표시줄과 그 이전의 상태행은 팝업 메시지 뒤에 있는 관련 정보의 시야를 가릴 수 있는 대화 상자보다 앞서, 미리 정의된 영역에 조언 메시지를 표시하기 위해 수년간 사용되어 왔다. 상태 표시줄(또는 상태행)의 사용에는 장점과 단점이 모두 존재한다.
상태 표시줄의 장점:

전체 화면을 보면서 동시에 메시지를 볼 수 있다 (단, 자신의 표시를 위해 화면 공간을 일부 차지한다).
상태 데이터를 보면서 정보를 입력할 수 있다.
상태 데이터를 보면서 다른 메뉴 옵션을 사용할 수 있다.
작동 중에 상태를 지속적으로 보여준다.
상태 표시줄의 단점:

정보를 한 줄 표시로 제한할 수 있다 (가변적인 다중 행 상태 표시줄/영역을 사용할 수도 있음).
상위 창이 다른 창 아래에 겹쳐져 있을 때 중요한 메시지를 위해 표면으로 튀어나올 수 없다 (하지만 상위 창이 위로 올라오면 항상 가시적이다).
화면 가장자리에 위치하여 대화 상자보다 눈에 덜 띌 수 있다.

예시
파일 관리자의 상태 표시줄은 현재 디렉터리의 항목 수, 총 크기 또는 현재 선택된 항목의 크기를 자주 보여준다.
웹 브라우저의 상태 표시줄은 사용자가 페이지를 보고 있을 때는 보이지 않거나 비어 있다가, 사용자가 하이퍼링크를 클릭하면 로딩 정보를 표시한다.
그래픽 편집기의 상태 표시줄은 치수, 색 공간 또는 이미지 해상도와 같은 현재 이미지에 대한 정보를 보여준다.
워드 프로세서에서 상태 표시줄은 종종 커서 위치, 문서의 페이지 수, Caps Lock, Num Lock, Scroll Lock 키의 상태를 보여준다. 또한 많은 워드 프로세서는 Insert 키에 이 세 키와 유사한 동작을 할당하여 삽입 모드 전환을 허용하며 – 이 상태 또한 상태 표시줄에 표시된다.
텍스트 어드벤처 게임은 종종 플레이어의 위치, 게임 시간, 점수와 같은 정보를 표시하는 상태행을 가졌다. 인포컴의 고객 뉴스레터는 《The New Zork Times》에서 이름을 바꾼 후 《The Status Line》이라는 명칭을 사용했다.
스프레드시트에서 상태 표시줄은 워드 프로세서와 유사한 정보를 보여주지만, 셀을 강조 표시하고 평균, 합계, 최대값 등을 보여주는 기능이 포함되어 있다.
