# Ledgerly 2.3 Release Notes

## New
- Export any report to CSV or PDF from the share menu.
- Recurring transactions can now end after a fixed number of payments.

## Changed
- Dark mode now follows the system setting by default. You can still force it under Appearance.

## Fixed
- Totals no longer double-count transfers between two of your own accounts.
- The widget refreshes after midnight instead of showing yesterday's balance.
